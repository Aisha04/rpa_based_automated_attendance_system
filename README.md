# RPA-Based Automated Attendance System

A **UiPath** automation that processes employee attendance from Excel files from start to finish. It calculates working hours, tracks lateness, detects absences, generates attendance reports and emails them automatically, with no manual spreadsheet work needed.

Custom calculations are written in **VB.NET** using UiPath's **Invoke Code** activity, for more flexibility and accuracy than standard activities alone.

---

## Features

- **Excel input processing:** reads raw attendance records (employee, date, check-in and check-out times)
- **Working hours calculation:** computes daily hours worked per employee
- **Lateness tracking:** flags employees who check in after the start time
- **Absence detection:** identifies employees with no attendance record for a day
- **Report generation:** produces a structured Excel attendance report
- **Automated email:** sends the report to the relevant recipients automatically
- **Custom VB.NET logic:** time and attendance calculations handled through Invoke Code

---

## How It Works

```
Attendance Excel file
        │
        ▼
Read Excel data (UiPath)
        │
        ▼
VB.NET calculations (Invoke Code)
  • Working hours
  • Lateness
  • Absences
        │
        ▼
Generate attendance report (Excel)
        │
        ▼
Send email with report attached
```

## Getting Started

### Requirements
- UiPath Studio
- Microsoft Excel
- An email account for sending reports (SMTP or Outlook)

### Run the project
1. Clone or download this repository.
2. Open `project.json` in UiPath Studio.
3. Update the input Excel file path and email settings in `Main.xaml`.
4. Run the workflow.
